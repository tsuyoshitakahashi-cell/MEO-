# 要求書（Requirements）— MEO AIO文章生成ツール

最終更新: 2026-05-06

---

## 1. プロジェクト概要

- **プロジェクト名**: MEOテキスト生成ツール
- **目的**: SHO-SAN社内のMEO担当者が、自社HPと競合HPのURLを入力するだけで、AIO（AI検索最適化）対策された GBP用テキスト群を一括生成できるWebアプリを提供する。担当者の作業時間を1案件あたり約2〜3時間 → 30分以下に短縮する。
- **主な利用者**: SHO-SANのMEO担当者（社内のみ）。クライアントには公開しない。
- **背景**: 既存ツール（gbp-eight.vercel.app）は4フィールド生成のみで、競合分析やAIO対策に対応していない。本プロジェクトでは「競合KW分析 + AIO最適化テキスト一括生成」に特化した新規Webアプリを構築する。

---

## 2. AIO対策の定義（本プロジェクト固有）

本プロジェクトにおける **AIO（AI Optimization）対策** は以下を両方満たす文章生成を指す。

### A. 生成AI検索（ChatGPT / Perplexity / Gemini）で引用されやすい構造
- 結論先出し（PREP法）
- 固有名詞・数字・実績の明示（年数・施工件数・受賞歴）
- Q&A形式の要素埋込
- 短い段落・明確な見出し
- E-E-A-T（Experience / Expertise / Authoritativeness / Trustworthiness）要素を含む
- 「○○とは」「特徴」「対応エリア」のような明示的な構造化表現

### B. Google SGE（AI Overviews）で抜粋されやすい構造
- 質問→回答の対応関係が明確
- 箇条書き / 表組みになる情報を文中に埋める
- 一文の意味が独立して取り出せる（コンテキスト独立）
- 曖昧表現（高品質・丁寧・親切）を具体数値・固有名詞に置換

両者で共通する原則: **「人間より先にAIが読む」前提で、引用されることを意識した構造化された日本語**。

## 3. 利用シナリオ

1. 担当者が新規クライアントのMEO案件を受任
2. アプリのURL（社内秘）にアクセス
3. 入力フォームに以下を入力
   - 自社HP URL（必須）
   - 競合工務店URL（3〜5個）
   - 会社名 / 業種（任意）
   - 追加KW（任意・競合分析結果に上書き可）
4. 「競合分析」ボタン押下 → 10個のKWをカテゴリ分けで提案
5. 担当者がKWを確認・取捨選択（チェックボックス）
6. 「文章生成」ボタン押下 → AIO対策された11種テキストを一括出力
   - ビジネス説明文 × 1
   - サービス説明 × 5（軸が異なる5種）
   - 商品説明 × 5（HPから自動抽出した上位5商品）
7. 各テキストをコピー or CSVダウンロードして、GBP管理画面に貼り付け
8. 案件を保存し、後日再編集可能

## 4. 機能要件

### 4.1 入力フォーム

| 項目 | 必須 | 用途 |
|---|---|---|
| 自社HP URL | ✓ | スクレイピング対象 |
| 競合工務店URL（3〜5個） | ✓ | 競合分析 |
| 会社名 | — | テキスト内の固有名詞 |
| 業種 | — | カテゴリ補強 |
| 追加KW | — | 競合分析提案に手動追加 |

### 4.2 競合分析機能

#### 入力
- 自社HP URL
- 競合HP URL（3〜5個）

#### 処理
1. 自社・競合の各HPを巡回（トップ + 内部リンク優先5ページ）
2. 競合HPの出現頻度KW分析（TF-IDFベース、自社HPと相対比較）
3. AI検索で引用されやすい構造的KW抽出（疑問形・How-to系・地域+サービス系）
4. 自社HPに不足しているKWを差分検出
5. 上記を統合し、Claude APIで10個のKWに精選
6. 5カテゴリに分類

#### 出力
- 計10個のKWを以下の5カテゴリに分類して提示

| カテゴリ | 例 |
|---|---|
| 地域系 | 飯塚市、福岡県、北九州エリア |
| 工法・サービス系 | 注文住宅、リノベーション、平屋 |
| ターゲット系 | 子育て世代、二世帯、シニア向け |
| 課題・悩み系 | 後悔しない家づくり、予算内、土地探し |
| 実績・権威系 | 創業30年、グッドデザイン賞、施工事例100件 |

- 各KWに対する以下のメタ情報を付与
  - 競合での出現回数
  - 自社HPでの出現回数
  - AI引用適性スコア（高/中/低）
  - 推奨度（必須/推奨/参考）

- 担当者がチェックボックスで採用KWを選択（デフォルト全選択）

### 4.3 文章生成機能（AIO対策）

採用KWと取得済みHP本文をベースに、以下11種のテキストを一括生成する。

#### ビジネス説明文 × 1（750字以内）
- HP全体（トップ・コンセプト・会社概要）から構成
- AIO対策ルール準拠
- 採用KW全体を自然に含める

#### サービス説明 × 5（各300字以内）
- 5種の生成軸を**自動で混合**して使い分ける（例ABC混合）
  - 軸例A: KW別（「注文住宅」「リノベーション」「平屋」など主要KWごと）
  - 軸例B: ターゲット別（「子育て世代向け」「二世帯住宅」「老後の住まい」など）
  - 軸例C: HP抽出別（HPの上位サービスページから自動抽出）
- AIが取得HP内容と採用KWから5種の最適な軸を自動決定
- ユーザーが希望すれば各軸の見出しを編集可能

#### 商品説明 × 5（各1000字以内）
- HPの `/project/` `/modelhouse/` `/works/` `/lineup/` 等から商品を自動抽出
- 上位5商品を選定（サムネイル/見出しで重要度判定）
- 各商品ごとにAIO対策テキストを生成
- 5商品未満の場合: 検出数のみ生成し、不足分は「該当なし」表示

### 4.4 出力UI

シングルページに以下を縦に配置:

```
[1. 入力フォーム]
   ↓ [競合分析実行]
[2. 競合KW提案結果（チェックボックス）]
   ↓ [文章生成実行]
[3. 生成テキスト群（11種）]
   - 各カードにコピーボタン / 文字数カウンタ / 使用KW表示
   - 一括CSVダウンロードボタン
```

### 4.5 案件管理

- 案件ごとに入力＋分析結果＋生成結果を保存
- 案件一覧画面で再編集可能
- 案件名・作成日・最終更新日でソート/検索

### 4.6 アクセス制御

- 認証機能は持たない（URLを社内のみで共有）
- 必要になった場合は Vercel Deployment Protection を後付けで有効化

## 6. スコープ外（やらないこと）

- NAP整合性チェック
- UTM URLジェネレータ
- 画像チェックリスト・ヒアリングシート出力
- Google Places API
- 写真の青空加工/個人情報検出（Vision API）
- クライアント企業への公開・SaaS化
- GBP API による自動投稿
- 多言語対応（日本語のみ）
