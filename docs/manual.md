# MEOテキスト生成ツール 操作マニュアル

最終更新: 2026-05-06
本番URL: **https://meo-text-tool.vercel.app**

---

## このツールでできること

自社の工務店HPのURLを入力するだけで、Googleビジネスプロフィール（GBP）に貼り付けられる **AIO対策済み** のテキストを11種類一括生成します。

| 生成テキスト | 個数 | 文字数上限 |
|---|---|---|
| ビジネス説明文 | 1個 | 750字 |
| サービス説明 | 5個（軸はAIが自動選定） | 各300字 |
| 商品説明 | 最大5個（HPから自動抽出） | 各1000字 |

競合工務店のURL（任意・最大5社）を追加すると、TF-IDF差分分析でより精度の高いキーワード提案が得られます。

---

## 1案件の所要時間

- 慣れれば 5〜10分
- AI処理時間: 競合分析 30〜60秒、文章生成 30〜60秒
- 案件管理: 入力フォームと案件保存で 1〜2分

## 操作手順

### Step 1: アクセス

ブラウザで **https://meo-text-tool.vercel.app** を開く。
URLは社内のみで共有してください（認証なし運用）。

### Step 2: 新規案件入力

トップ画面の入力フォームに以下を入れる。

| 項目 | 必須 | 例 |
|---|---|---|
| 案件名 | ✓ | 株式会社サンプル工務店A |
| 自社HP URL | ✓ | https://example-komuten.co.jp/ |
| 競合HP URL | — | 同地域・同規模の競合工務店URL（最大5社） |

**競合URLは空のままでもOK** です。入力すると差分分析の精度が上がります。

### Step 3: 競合分析を実行

「競合分析を実行」ボタンを押す。**30〜60秒** かかります。
完了すると、提案キーワード10個がカテゴリ別（地域系/工法・サービス系/ターゲット系/課題・悩み系/実績・権威系）で表示されます。

各KWには以下のメタ情報が付きます。

- **推奨度バッジ**: 必須（赤）／推奨（黄）／参考（灰）
- **AI引用適性**: high / mid / low
- **自社X / 競合Y**: 出現回数
- **選定理由**: なぜこのKWが選ばれたかの説明

### Step 4: KWを選択

採用したいKWのチェックボックスをON/OFFします。
初期状態では「必須」「推奨」が自動選択されています。
チェックされたKWだけが文章生成で使用されます。

### Step 5: 文章生成

「選択中のXKWで AIO文章を一括生成」ボタンを押す。**30〜60秒** かかります。
完了すると、11種テキストがカード形式で表示されます。

各カードには:
- **コピーボタン**（GBPに貼り付け用）
- **文字数カウンタ**（上限超過時は赤字）
- **使用KW**（実際に文章内に含まれたKW）
- **CSVダウンロード**（11種一括）

### Step 6: 案件保存

「案件を保存」ボタンを押す。
DBに保存され、案件詳細ページ `/cases/[id]` に遷移します。
後日「案件一覧」から再編集できます。

### Step 7: GBPに反映

各テキストを「コピー」して、Googleビジネスプロフィールの該当フィールドに貼り付けます。

| 生成テキスト | GBP のフィールド |
|---|---|
| ビジネス説明文 | プロフィール → 説明 |
| サービス説明 | サービス → サービス追加 → 説明 |
| 商品説明 | 商品 → 商品追加 → 説明 |

## 案件管理

### 案件一覧

ヘッダー「案件一覧」リンク → `/cases`
- 最新更新順にソート
- バッジで「競合分析済 / 文章生成済」が一目でわかる
- クリックで詳細・再編集ページへ

### 再編集

`/cases/[id]` で過去の案件を再表示。
状態が完全復元され、KWのチェックを変えて再生成 → 「案件を更新」で上書き保存できます。

### 削除

案件一覧の右側「削除」 → 確認後「削除（赤）」で完全削除。

## AIO対策とは

本ツールが施す **AIO（AI検索最適化）対策** は以下を満たします。

1. **結論先出し（PREP法）**: 各文の冒頭で結論
2. **固有名詞・数字・実績の明示**: 創業年・施工棟数・賞名・等級・地域名
3. **曖昧表現の禁止**: 「高品質」「丁寧」→ 具体数値・固有名詞へ
4. **Q&A要素を埋込**: 「○○とは」「特徴」「対応エリア」のような構造化表現
5. **一文の独立性**: 各文単独で意味が通る（AI引用しやすさ）
6. **E-E-A-T要素**: 経験・専門性・権威性・信頼性
7. **採用KWの自然な挿入**: 各テキスト内で2〜3回

これにより ChatGPT / Perplexity / Gemini / Google SGE の生成AI検索で **引用されやすい** GBPプロフィールになります。

## よくある質問

### Q1. 競合URLが3社揃わなくても使える？

→ **はい、0社でもOK**。空のままで「競合分析を実行」できます。
ただし競合データがないと、Geminiは「自社HP内容 + 工務店業界一般のベストプラクティス」のみで推薦します。精度を上げたい場合は3社以上の入力を推奨します。

### Q2. 生成テキストが文字数を超過した

→ 内部で末尾を自動切り詰めしているので超過のまま出ることはありません。
切れ味がおかしい場合は、KWを減らすか別のKW組み合わせで再生成してください。

### Q3. 「Gemini API が一時的に高負荷状態です」と出た

→ Google Gemini側の一時的な過負荷です（503）。本ツールは自動で4回リトライしますが、それでも回復しない場合は **数分待って再実行** してください。

### Q4. HP がうまく読み込めない（本文が薄い）

→ 以下のいずれかが原因の可能性:
- HPが JavaScript レンダリング必須（cheerio で取得不可）
- HPが bot 拒否設定（403/429）
- HPの構造が独特で内部リンクを抽出できない

→ 自動的にトップページのテキストだけで生成を続けます。出力品質が低い場合はクライアントに直接ヒアリングして補強してください。

### Q5. 商品が5個未満しか抽出されない

→ HPに `/modelhouse/` `/product/` `/lineup/` 等のパスを持つ商品ページが少ない場合、検出数のみ生成されます（最低1個）。

### Q6. 案件名はあとから変更できる？

→ できます。案件詳細ページで案件名を編集して「案件を更新」を押すと反映されます。

### Q7. 競合URLは何社くらい入れるのが理想？

→ **3〜5社が推奨**です。同地域・同規模・同業種の工務店を選ぶと差分KWが具体的になります。

### Q8. 1案件あたりのコストは？

→ Google Gemini 2.5 Flash の **無料枠** で運用しています。費用は発生しません。
レート制限: 15リクエスト/分、1Mトークン/日、1500リクエスト/日（1日数十案件まで余裕）

## 旧ツール（gbp-eight）との違い

| 項目 | gbp-eight | MEOテキスト生成ツール（本ツール） |
|---|---|---|
| 競合分析 | なし | あり（TF-IDF + Gemini精選） |
| 生成テキスト | 4種 | **11種** |
| AIO対策 | LLMO汎用 | AIO（生成AI検索）+ Google SGE 両対応 |
| 案件保存 | なし | あり（DB保存・再編集） |
| 商品自動抽出 | なし | あり（HPから上位5商品を自動検出） |

新規案件は本ツールで作成してください。
